# docs/ — Tài liệu dự án

Thư mục này chứa **bản sao local** của các trang GitHub Wiki, dùng để:

1. **Backup** — phòng khi GitHub Wiki gặp sự cố
2. **Offline reference** — đọc khi không có mạng
3. **Git-tracked** — có history thay đổi, dễ review
4. **Mirror với Wiki** — sau khi sửa file ở đây, copy paste lên Wiki

## Quy ước đặt tên file

| Wiki page | File trong docs/ |
| --------- | ---------------- |
| Home | `home.md` (lowercase, dễ gõ) |
| 01-Project-Direction-and-Rationale | `01-project-direction.md` |
| 02-Research-Evidence-and-Decisions | `02-research-evidence.md` |
| 03-Business-Model-Canvas | `03-business-canvas.md` |
| 04-MVP-Scope-and-Implementation-Plan | `04-mvp-plan.md` |

## Workflow

1. Sửa file ở `/wiki/*.md` (đã có sẵn ở root)
2. Copy xuống `/docs/*.md` (lowercase) cho Git tracking
3. Sau khi review → copy paste lên GitHub Wiki tab

> ⚠️ **Lưu ý:** GitHub Wiki **KHÔNG tự sync** với `/wiki/` folder. Hai nơi phải được cập nhật **song song**.
